# Fonts

Magister's faces are all open-source Google Fonts under the SIL Open Font License — **Chakra Petch** (display, 400–700), **IBM Plex Sans** (body, 300–600), **JetBrains Mono** (telemetry, 400–600), and the **Material Symbols Sharp** icon font — and `tokens.css` loads them by URL with a Google Fonts `@import`, so no font files live in this folder and nothing is uploaded to Claude Design.
