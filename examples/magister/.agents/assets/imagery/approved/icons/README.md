# Icons — Material Symbols Sharp

Chosen on the style test (`../../tests/style-test.html` → Iconography): Sharp's right angles match Chakra Petch's cut corners and read as machined console; Rounded reads friendly-consumer, and Lucide's thin 2px stroke is lighter than IBM Plex's stems.

- **Load:** Google Fonts `Material Symbols Sharp` (Apache 2.0), `opsz,wght,FILL,GRAD@20..48,400..700,0..1,0`. Nothing to download — no files live here.
- **Sizes:** 20px in dense UI, 24px default, 40px for feature cards. `opsz` follows size.
- **Weight 400. Outline by default; `FILL 1` only for an active/selected state.**
- **Colour:** the text colour. Never the action green unless the icon *is* the action.
